# NetWhisper — Project Log

## 1. Project Overview

**Title:** NetWhisper: Reliable Data Communication over an Acoustic Channel

NetWhisper is an academic Computer Networks project that explores transmitting digital data between nearby devices using sound generated by a speaker and captured by a microphone.

The project will implement packet-based communication, error detection, acknowledgement, retransmission, and performance analysis.

## 2. Problem Statement

Conventional device communication commonly uses technologies such as Wi-Fi and Bluetooth. NetWhisper explores an alternative communication medium while demonstrating networking principles through a real-device prototype.

## 3. Objectives

- Convert text into binary data and reconstruct it.
- Encode binary data using Frequency Shift Keying (FSK).
- Transmit data through a speaker and receive it through a microphone.
- Introduce packetization and error detection using CRC.
- Implement ACK/NACK and retransmission where feasible.
- Measure latency, throughput, and transmission errors.
- Build a dashboard for monitoring communication results.

## 4. Computer Networks Concepts

- Data communication and protocol design

- FSK modulation and demodulation

- Error detection using CRC
- Reliable data transfer, acknowledgements, and retransmission

## 10. Limitations

Acoustic transmission may be affected by distance, room acoustics, background noise, speaker and microphone frequency response, and device audio processing. The prototype is not intended to replace Wi-Fi or Bluetooth.

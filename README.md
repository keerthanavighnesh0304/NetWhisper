# NetWhisper
Acoustic Data Communication using Speaker and Microphone.

NetWhisper transmits digital data between nearby devices using sound generated by speakers and captured by microphones via Continuous-Phase Frequency Shift Keying (CPFSK).

---

## Acoustic Protocol Specification

### 1. Physical Layer (FSK)
- **Audio Sampling Rate**: $44100\text{ Hz}$ (CoreAudio default)
- **Space Frequency (Bit 0)**: $1800\text{ Hz}$
- **Mark Frequency (Bit 1)**: $2400\text{ Hz}$
- **Symbol Duration**: $40\text{ ms}$ per bit ($25\text{ bps}$ baud rate, robust against indoor room reverberation)
- **Modulation**: Continuous-Phase FSK (CPFSK) to eliminate wideband spectral splatter

### 2. Data Link Layer (Framing & Error Detection)

```text
[ Guard: 50ms ] + [ Chirp Preamble: 200ms ] + [ Guard: 50ms ] +
[ SYNC: 0xAC (1B) ] + [ SEQ (1B) ] + [ LEN: N (1B) ] + [ PAYLOAD (N Bytes) ] + [ CRC-16 (2B, Big-Endian) ] +
[ Guard: 50ms ]
```

- **Preamble Chirp**: Linear sweep $1200\text{ Hz} \to 2800\text{ Hz}$ ($200\text{ ms}$, Hanning-tapered) detected via FFT cross-correlation matched filtering.
- **Sync Delimiter**: `0xAC` (`0b10101100`, 1 byte) for sample-accurate symbol timing alignment.
- **Sequence Number (`SEQ`)**: 1 byte (`0` to `255`, wrapping modulo 256).
- **Length Header (`LEN`)**: 1 byte ($N$, $0 \le N \le 255$ bytes, supports empty string $N=0$).
- **Payload**: $N$ UTF-8 bytes.
- **CRC-16-CCITT Checksum**:
  - Polynomial: `0x1021` ($x^{16} + x^{12} + x^5 + 1$)
  - Initial Value: `0xFFFF`
  - Coverage: `[SEQ] + [LEN] + [PAYLOAD]`
  - Byte Order: Big-Endian (High Byte first, Low Byte second)
  - Validation: Corrupted frames are rejected immediately with `crc_valid: False`.

## Installation & Requirements

macOS with Python 3.10+:
```bash
pip3 install sounddevice numpy scipy
```

---

## CLI Execution Commands

### 1. Run Automated Unit Tests (Software)
```bash
python3 fsk_engine.py --test-automated
```

### 2. Run Physical Acoustic Loopback (Speaker → Air → Mic)
*Ensure volume is set to 60–80% and microphone is unmuted:*
```bash
python3 fsk_engine.py --test-acoustic
```

### 3. Acoustic Transmission Between Two Laptops
- **Laptop B (Receiver)**:
  ```bash
  python3 fsk_engine.py --listen 10
  ```
- **Laptop A (Sender)**:
  ```bash
  python3 fsk_engine.py --send "NETWHISPER" --seq 1
  ```

## Integration Contract (FastAPI Dashboard)

For teammate Keerthana's backend:

```python
import fsk_engine

# 1. Transmit text
res = fsk_engine.transmit_text("Hello NetWhisper!", seq_num=1)
# Returns:
# {
#     "success": True,
#     "message": "Hello NetWhisper!",
#     "seq_num": 1,
#     "crc_16": 18406,
#     "crc_hex": "0x47E6",
#     "duration_sec": 4.8,
#     "bytes_sent": 17,
#     "error": None
# }

# 2. Receive text
msg, meta = fsk_engine.receive_text(timeout_seconds=10.0)
# Returns (decoded_text, meta):
# msg -> "Hello NetWhisper!" (or None if CRC fails or times out)
# meta -> {
#     "success": True,
#     "message": "Hello NetWhisper!",
#     "seq_num": 1,
#     "crc_valid": True,
#     "expected_crc": 18406,
#     "received_crc": 18406,
#     "timeout_seconds": 10.0,
#     "peak_correlation": 42.1,
#     "correlation_ratio": 22.5,
#     "sync_matches": 8,
#     "length_bytes": 17,
#     "error": None
# }

# 3. Retrieve stats
stats = fsk_engine.get_stats()
```
